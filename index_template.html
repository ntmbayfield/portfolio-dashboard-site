Nonprofit Fundraising Analytics

Dashboard Portfolio

A suite of reporting dashboards built for a nonprofit development office — annual performance, donor retention, campaign goal tracking, and weekly gift reporting.

All data on this site is fictional. These dashboards were rebuilt for portfolio purposes with randomly generated donors, gifts, campaigns, and revenue figures for a fictional organization, "Northgate Youth Foundation." No real constituent records, donor names, or organizational financials appear anywhere on this site. The dashboard design, calculation logic, and data model are my own work.

Each dashboard is a single self-contained HTML file — no build step, no server, no database. Data is pre-aggregated at build time and embedded as JSON, then rendered client-side with Chart.js. That keeps them fast to load, trivial to host, and easy to hand to a colleague as a file.

The underlying source data in production is gift-level export from Raiser's Edge NXT, transformed into the metrics below. The Dashboard Reference documents every metric definition, filtering rule, and data relationship behind these pages.

What this work involved

  • Designing donor-movement logic (New / Retained / Recaptured / Lapsed / LYBUNT / SYBUNT) from gift-level data keyed on constituent ID across fiscal years.
  • Reconciling a campaign reclassification project and quantifying its effect on reported revenue year over year.
  • Building a repeatable weekly reporting pipeline with cumulative fiscal-year-to-date rollups by campaign, appeal, and fund.
  • Writing the metric definitions, filtering rules, and standard operating procedures so the reports can be reproduced by someone else.
